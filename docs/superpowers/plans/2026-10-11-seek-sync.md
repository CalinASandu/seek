# Seek sync between PCs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Search on any linked PC also finds files on the other linked PCs (and every drive they have seen), synced
incrementally over the LAN, encrypted, with 6-digit-code pairing.

**Architecture:** A new OS-independent crate `seek-sync` holds the change journal, wire format, Noise transport,
SPAKE2 pairing, peer store and the transport-agnostic sync session (driven through a `SyncHost` trait). The service
implements `SyncHost` over its existing state, runs a TCP listener/dialer + mDNS, and exposes pairing/sync requests
on the named pipe. Remote devices are ordinary registry devices whose `indexed_by_host` is the owner PC.

**Tech Stack:** Rust 2021 (MSRV 1.85), tokio, `snow` 0.9 (Noise IK), `spake2` 0.4, `chacha20poly1305` 0.10,
`postcard` 1, `zstd` 0.13, `mdns-sd`, `rand` 0.8; Tauri 2 + React/TypeScript UI.

**Spec:** `docs/superpowers/specs/2026-10-11-seek-sync-design.md`

## Global Constraints

- `seek-core` and `seek-sync` must have **no Windows dependencies** (future Linux/macOS).
- Timestamps are unix epoch **milliseconds** everywhere.
- Max **5** PCs per group. Pairing code: **6 digits**, valid **2 min**, **3** attempts.
- TCP port **47321** (configurable; tests use port 0). mDNS service type `_seek._tcp.local.`.
- Sync tick **60 s**; **Sync now** pushes immediately.
- Journal cap **~50 MB per device** (`JOURNAL_MAX_BYTES = 50 * 1024 * 1024`).
- Speed targets: full copy of 2M entries < 2 s on gigabit LAN; apply 1,000 changes < 50 ms.
- Firewall rule only for the **Private** profile.
- Access: elevated caller sees everything; otherwise other users' profile folders are hidden (linked users count as
  the same person on both PCs).
- Never `git commit` without the user's explicit request; delete stray empty files agents leave in the repo root.

## Review Focus

1. **USB stick known to both PCs** — `poll_volumes` must never match a *remote* device by identity and start
   scanning/updating it; the local PC registers its own record. Test in Task 7.
2. **Index replaced while a full copy is being prepared** — the snapshot's cursor must match its contents (taken
   under the same locks). Test in Task 8 (`full_copy_cursor_matches_contents`).
3. **Peer restarts / connection drops mid full copy** — receiver keeps the old copy and its old cursor; next session
   resumes. Test in Task 6 (`dropped_connection_keeps_old_copy`).
4. **Peer reinstalled (new key, same host id)** — refused and marked `NeedsRelink`, never silently re-trusted.
   Test in Task 9.
5. **Non-elevated user sees another user's folder on a remote PC** — must be hidden unless linked. Test in Task 11.

```rust
    self.devices.iter().find(|d| &d.identity == ident && d.indexed_by_host == self.host_id)
}

/// Devices hidden because another record describes the same physical device (see the sync spec §6).
pub fn hidden_duplicates(devices: &[Device], local: HostId) -> std::collections::HashSet<DeviceId> {
    use std::collections::HashMap;
    let mut groups: HashMap<&DeviceIdentity, Vec<&Device>> = HashMap::new();
    for d in devices {
        groups.entry(&d.identity).or_default().push(d);
    }
    let mut hidden = std::collections::HashSet::new();
    for (_, g) in groups.into_iter().filter(|(_, g)| g.len() > 1) {
        let connected = |d: &Device| d.indexed_by_host == local
            && matches!(d.state, crate::DeviceState::Online | crate::DeviceState::Scanning);
        let keep = g.iter().max_by(|a, b| {
            (connected(a), a.index_updated_at, a.indexed_by_host == local, std::cmp::Reverse(a.id))
                .cmp(&(connected(b), b.index_updated_at, b.indexed_by_host == local, std::cmp::Reverse(b.id)))
        }).unwrap().id;
        hidden.extend(g.iter().map(|d| d.id).filter(|id| *id != keep));
    }
    hidden
}
```

```rust
pub enum Since { UpToDate, Delta(Vec<seek_core::Change>), Full }

pub struct DeviceJournal { /* generation, first_seq, last_seq, batches: VecDeque<(u64, Vec<Change>, usize)>, bytes, path, max_bytes */ }
impl DeviceJournal {
    pub fn open(path: PathBuf, max_bytes: usize) -> DeviceJournal; // missing/corrupt file → new generation, seq 0
    pub fn in_memory(max_bytes: usize) -> DeviceJournal;            // tests
    pub fn cursor(&self) -> Cursor;
    pub fn record(&mut self, changes: &[Change]);                   // seq += 1; appends to file (best effort, logs on error)
    pub fn reset(&mut self);                                        // new generation, seq 0, file truncated
    pub fn since(&self, c: &Cursor) -> Since;
}
pub const JOURNAL_MAX_BYTES: usize = 50 * 1024 * 1024;
```

File format `journal\<device>.log`: `b"SEEKJRN1"`, 16-byte generation, then records `u32 LE len | postcard((seq: u64,
changes: Vec<Change>))`. A truncated last record is ignored (crash mid-append). When dropping old batches pushes the
file over `2 * max_bytes`, rewrite it (header + kept batches) atomically (`.tmp` + rename).

```rust
pub fn since(&self, c: &Cursor) -> Since {
    if c.generation != self.generation || c.seq > self.last_seq { return Since::Full; }
    if c.seq == self.last_seq { return Since::UpToDate; }
    // first kept batch must be c.seq + 1
    if self.first_seq > c.seq + 1 { return Since::Full; }
    Since::Delta(self.batches.iter().filter(|(s, _, _)| *s > c.seq).flat_map(|(_, ch, _)| ch.iter().cloned()).collect())
}
pub fn record(&mut self, changes: &[Change]) {
    self.last_seq += 1;
    let bytes = postcard::to_stdvec(&(self.last_seq, changes)).expect("serializable");
    self.append_to_file(&bytes);           // u32 len + bytes; logs a warning on error
    self.bytes += bytes.len();
    self.batches.push_back((self.last_seq, changes.to_vec(), bytes.len()));
    while self.bytes > self.max_bytes && self.batches.len() > 1 {
        let (_, _, n) = self.batches.pop_front().unwrap();
        self.bytes -= n;
    }
    self.first_seq = self.batches.front().map_or(self.last_seq + 1, |b| b.0);
    // rewrite file when it holds > 2× max_bytes (track file_bytes separately)
}
```

`first_seq` for an empty journal = `last_seq + 1` (so `since` of the current cursor is UpToDate and older → Full).

```rust
#[serde(tag = "t", rename_all = "camelCase", rename_all_fields = "camelCase")]
pub enum Msg {

    Hello { protocol: u32, host_id: uuid::Uuid, name: String },

    fn outgoing(&self, device: uuid::Uuid, have: Option<Cursor>) -> Option<Outgoing>;

    fn held(&self, owner: uuid::Uuid) -> Vec<(uuid::Uuid, Cursor)>;

    fn apply_full(&self, owner: uuid::Uuid, device: uuid::Uuid, cursor: Cursor, bytes: Vec<u8>) -> Result<(), String>;

pub async fn run_session<R, W>(host: Arc<dyn SyncHost>, peer: uuid::Uuid, rd: SecureReader<R>, wr: SecureWriter<W>,
    ctl: Arc<SessionCtl>, outbox_rx: tokio::sync::mpsc::UnboundedReceiver<Msg>, interval: Duration) -> Result<(), Error>;
```

Behaviour of `run_session`:
1. Send `Hello`, `Devices{shared, profiles}`, `Have{held(peer)}`. Expect peer `Hello` first: protocol mismatch →
   `Err(Protocol("version"))`; `host_id != peer` → error.
2. A reader task forwards decoded `(Msg, payload)` into an mpsc; the main loop `select!`s on: incoming msg, tick,
   `sync_now.notified()`, `stop.notified()`, outbox.
3. Owner side bookkeeping: `sent: HashMap<DeviceId, Cursor>` initialised from the peer's `Have`; devices the peer
   lacks are sent with `have = None` (→ Full). `push()` = for each shared device: `host.outgoing(id, sent.get(id))`
   → send Delta/Full, set `sent[id] = to/cursor`. Also resend `Devices` if the list (ids + `index_updated_at` +
   `display_name` + `state`) changed since last sent. `push()` runs after receiving `Have`, on every tick, on
   `SyncNow` received, and on local `sync_now`. On local `sync_now` also send `Msg::SyncNow` to the peer.
4. Receiver side: `Delta` → `apply_delta`; `Full` → `apply_full` (blocking work in `spawn_blocking`); on success
   send `Ack`; on failure log and send `Have{[(device, zero cursor)]}` (nil generation) so the owner sends a Full.
   `Devices` → `remote_devices`. After processing any data message call `synced(peer)`.
5. `Ack` → `sent[device] = cursor`. `Unlinked` → `unlinked_by(peer)` and return Ok. `MemberJoined` →
   `member_joined`.
6. Payload codecs: `delta_payload(changes) = zstd::encode_all(postcard::to_stdvec(changes), 1)`; decode reverse.

Behaviour:
- Listener `TcpListener::bind(("0.0.0.0", port))`; first byte of a connection: `b'P'` → pairing, `b'N'` → session.
  The dialer writes that byte first.
- **Session accept**: `noise::accept(.., |k| store.by_key(k) is Linked)`. If the key is unknown but the dialer's
  Hello (first Msg) carries a known `host_id` → mark that peer `NeedsRelink`, emit, drop. (To learn the host id of a
  refused key, accept with `|_| true`, read `Hello`, then close if the key isn't that peer's stored key.)
- **Dialer** loop every `interval` and when mDNS resolves a peer: for each `Linked` peer not in `sessions` with
  `self.host_id < peer.host_id` (lower id dials) and a known addr → `TcpStream::connect` (timeout 3 s) → `b'N'` →
  `noise::connect(.., peer key)` → `run_session`. The higher id also dials if it has not heard from the peer for
  2 × interval (covers one-sided reachability); the accept side drops a duplicate session for the same host.
- On session start: `connected.insert`, owner's devices state recomputed (`remote_devices` refresh), emit. On end:
  remove, mark that owner's devices Offline, emit `PeersChanged`, `invalidate`.
- **mDNS** (when `cfg.mdns`): register `_seek._tcp.local.` instance `host_id`, TXT `name`, port; browse the same
  type; resolved services → `discovered` (excluding self) and update `addr` of linked peers (save store).
  Use the mdns-sd version pinned in Cargo.toml; check its `ServiceEvent` API with context7 before coding.
- **Pairing host** (`b'P'` accepted): if no usable code → reply error byte and close. Else
  `consume_attempt()`; run `pair_host(code, mine)` where `mine.members` = current peers as `MemberInfo`.
  Success → if peers+1 ≥ `MAX_PCS` → refuse (send nothing further; guest sees an error) — check **before** SPAKE2 by
  sending a status byte `1 = ok, 0 = full, 2 = no code` right after the `b'P'`. Store guest as `Peer` with
  `linked_users = [(code_creator_sid, guest.user_sid)]` (`start_pairing` records the creator's SID, so its
  signature is `start_pairing(&self, user_sid: &str) -> PairingCode`), clear the code, then send
  `Msg::MemberJoined{guest}` to every connected session; each member stores the newcomer as a Linked peer with **no**
  linked users (user links exist only between the two PCs where the pairing happened — documented limitation).
  Dial the guest immediately.
- **Pairing guest** (`join`): connect, send `b'P'`, read status byte, `pair_guest`, store host + every `members`
  entry as Linked peers (host gets `linked_users = [(user_sid, host.user_sid)]`), save, dial all.
- **Unlink**: send `Msg::Unlinked` over the session (if connected), stop it, remove the peer, delete all its
  devices (records, indexes, files, cursors), save, emit. `unlinked_by(peer)` (from the session) does the same
  without sending.
- `sync_now`: `ctl.sync_now.notify_one()` on every session.

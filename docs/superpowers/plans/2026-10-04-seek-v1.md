# Seek v1 (Local, Windows) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working version of Seek: instant file-name search across all local drives and
network shares on Windows, remembering offline devices, with a polished Tauri desktop UI.

**Architecture:** Rust workspace. `seek-core` (OS-agnostic index/query/search/persistence) is used by
`seek-scan` (Windows MFT/USN/walker scanners) and `seek-service` (elevated service owning all indexes,
serving a named-pipe JSON protocol defined in `seek-ipc`). The Tauri 2 + React + TypeScript app talks to
the service over the pipe and scans network shares under the user's credentials.

**Tech Stack:** Rust 1.93 (MSVC), `windows-sys`, `windows-service`, `tokio`, `rayon`, `memchr`, `regex`,
`zstd`, `serde`/`serde_json`, `uuid`, `chrono`, `jwalk`, `notify`, `criterion`; Tauri 2, React 19,
TypeScript, Vite, `@tanstack/react-virtual`, `lucide-react`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-04-seek-local-design.md` — read it before starting any task.

## Global Constraints

- Windows 10/11 x64 only (`x86_64-pc-windows-msvc`); `seek-core` must not depend on any Windows crate.
- License: `MIT OR Apache-2.0` in every `Cargo.toml` and `package.json`.
- Names-only search; no content search; no global hotkey; hidden/system files indexed and shown.
- Pipe name `\\.\pipe\seek-v1`; frames = `u32` little-endian length + UTF-8 JSON; protocol version `1`.
- Data directory `%ProgramData%\Seek` (override with `--data-dir`): `host.json`, `devices.json`, `indexes\<uuid>.seekidx`.
- Timestamps are unix epoch milliseconds (`i64`) everywhere in Rust and on the wire.
- Index file magic `SEEKIDX\0`, format version `1`; unknown versions are ignored, never panic.
- File ids: NTFS FRN masked to low 48 bits; NTFS root id `5`; walker root id `0`.
- Targets: query < 50 ms p95 on 10M entries; NTFS index of 1M entries < 10 s; app searchable < 1 s.
- The executing shell is **not elevated**; anything needing admin must have a non-admin test path.
- Do not commit; the coordinator commits after each wave. Do not edit files owned by another task.

## Review Focus

1. **Unicode names** (`Ünïcödé.txt`, `日本語.pdf`, emoji, `İ`): case-insensitive matching must work even when lowercasing changes byte length → tests in Task 2 (index) and Task 4 (search).
2. **Half-typed queries** (`ext:`, `size:>`, `"unclosed`, lone `|`, `!`, `dm:20`): parser never panics, returns `ParseError{position}`, UI keeps last results → tests in Task 3 and Task 9.
3. **Corrupt, truncated, empty or future-version `.seekidx`** files: load returns an error, service rescans, no crash → tests in Task 2 (persist) and Task 7.
4. **Device disappears mid-scan / mid-follow** (USB yanked): device becomes Offline, the previous index is kept and still searchable → test in Task 7 with a fake volume source.
5. **Huge result sets** (empty query over millions of rows; `FetchRows` beyond the end): service never sends the full set, beyond-end returns empty rows, UI scrolls smoothly → tests in Task 4 and Task 7, bench in Task 4.

**Rules:**
- `from_raw`: drop the entry whose `id == root_id`; entries whose `parent_id == root_id` get `NO_PARENT`; entries whose parent chain does not reach the root (orphans/cycles) are dropped with their descendants. Lower-cased name = `name.to_lowercase()` stored in a separate arena (lengths may differ).
- `apply`: `Upsert` of a known id updates every field (name re-appended to arenas, parent re-resolved; unknown parent → treat as orphan: mark dead); `Upsert` of a new id appends; `Delete` marks dead and removes from `id_to_row`. Deleting a folder also marks all live descendants dead (O(n) pass acceptable).
- `compact`: drops dead rows, rebuilds arenas, remaps parents; idempotent.
- File layout: `MAGIC(8) | version u32 LE | header_len u32 LE | header JSON | zstd(body)`; body = for each column in fixed order (ids, parents, name_off, name_len, lower_off, lower_len, sizes, modified, created, attrs) `u64 LE byte length + raw LE bytes`, then names and lower arenas likewise. `encode` compacts first. `decode` validates magic, version (≠1 → `Error::Format("unsupported version N")`), column lengths all equal `rows`, offsets within arenas, parents < rows or `NO_PARENT`, valid UTF-8 — any failure is `Error::Format`, never panic.
- `save_index` writes `<path>.tmp` then `std::fs::rename`.
- `registry`: `devices.json` = `{ "hostId": ..., "devices": [...] }`; missing file → new random host id; `host.json` not needed (host id lives in devices.json).

### Task 3: Query parser (Agent A)

**Files:** Create `crates/seek-core/src/query.rs` (tests inline).

**Produces:**

```rust
pub enum Expr { And(Vec<Expr>), Or(Vec<Expr>), Not(Box<Expr>), Term(Term) }
pub enum Term {
    Text { needle: String /*lowercased*/, on_path: bool },
    Wildcard { pattern: String /*lowercased, contains * or ?*/, on_path: bool },
    Regex { pattern: String },
    Ext(Vec<String>),                          // lowercased, no dot
    Size { min: Option<u64>, max: Option<u64> },       // inclusive bytes
    Modified { min: Option<i64>, max: Option<i64> },   // inclusive unix ms
    Device(String),                            // lowercased substring of display_name
    FoldersOnly, FilesOnly, OnlineOnly, OfflineOnly,
}
pub struct ParseError { pub message: String, pub position: usize /* char index */ }
pub fn parse(input: &str) -> Result<Expr, ParseError>;                       // uses chrono::Local::now()
pub fn parse_at(input: &str, now: chrono::DateTime<chrono::FixedOffset>) -> Result<Expr, ParseError>;
```

**Grammar:** whitespace separates AND-ed groups; `|` (with or without spaces around it) joins terms into an OR
group and binds tighter than AND (`a b | c` = `a AND (b OR c)`); `!` prefix negates the next term;
`"..."` is a literal (spaces kept). Prefixes (case-insensitive): `ext:` (`;`-separated), `size:` (`>N`, `>=N`,
`<N`, `<=N`, `N`, `A..B`; units `b kb mb gb tb`, 1024-based, decimals allowed), `dm:` (`today`, `yesterday`,
`YYYY`, `YYYY-MM`, `YYYY-MM-DD`, with optional `>`,`>=`,`<`,`<=` or `A..B`; local time from `now`'s offset),
`path:` (applies to the following text/wildcard), `regex:` (rest of token, or quoted), `device:`, `folder:`,
`file:`, `online:`, `offline:`. Empty input → `Expr::And(vec![])` (matches everything). An unknown `xyz:foo`
is plain text `xyz:foo`. Errors: empty `ext:`/`size:`/`dm:`/`regex:` value, bad number/date, invalid regex,
unclosed quote, dangling `|` or `!` — each with the char position where it occurs. Must never panic on any
input (fuzz-like test below).

### Task 4: Matcher, parallel search, synthetic data, benchmark (Agent A)

**Files:** Create `crates/seek-core/src/{matcher.rs,search.rs,synth.rs}`, `crates/seek-core/benches/search.rs`.

**Produces:**

```rust
pub struct SearchDevice<'a> { pub device: &'a Device, pub index: &'a DeviceIndex, pub mount: &'a str, pub online: bool }
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Hit { pub dev: u16, pub row: u32 }
pub fn search(devs: &[SearchDevice], expr: &Expr, sort: SortKey, descending: bool,
              cancelled: &(dyn Fn() -> bool + Sync)) -> Option<Vec<Hit>>;     // None when cancelled
pub fn materialize(devs: &[SearchDevice], hit: Hit) -> ResultRow;
pub fn synth_index(n: usize, seed: u64) -> DeviceIndex;    // realistic names/extensions/depths; deterministic
```

**Rules:** compile `Expr` once into a matcher (`memchr::memmem::Finder` per text needle; wildcards → anchored
case-insensitive `regex`; `Regex` term → `RegexBuilder::case_insensitive(true)`). Evaluate cheap per-row
predicates (alive, folder/file, ext, size, modified, device, online) before name matching. `on_path` terms
build the lower-cased full path only for rows that passed everything else. Parallelise with rayon over
devices and row chunks (64k rows); check `cancelled()` per chunk. Sort: `Name` = by `name_lower` then path;
`Path` = by lower-cased full path; `Size`, `Modified` numeric (ties by name); `Device` by display name then
name. Folders have size 0. Empty `Expr::And(vec![])` returns all live rows.

**NTFS reference (put these offsets in `mft.rs` as named consts):**
- Open volume: `std::fs::OpenOptions::new().read(true).share_mode(FILE_SHARE_READ | FILE_SHARE_WRITE).open(r"\\.\C:")` (`std::os::windows::fs::OpenOptionsExt`). Access denied → `ScanError::AccessDenied`.
- `DeviceIoControl(handle, FSCTL_GET_NTFS_VOLUME_DATA)` → `NTFS_VOLUME_DATA_BUFFER`: `BytesPerSector`, `BytesPerCluster`, `BytesPerFileRecordSegment`, `MftStartLcn`, `MftValidDataLength`.
- Read record 0 at `MftStartLcn * BytesPerCluster`; its unnamed `$DATA` runs = the MFT's extents.
- FILE record: magic `b"FILE"` @0; update-seq offset `u16`@4; update-seq count `u16`@6; first attr offset `u16`@20; flags `u16`@22 (`0x1` in use, `0x2` directory); base record ref `u64`@32 (low 48 bits; 0 = base record).
- Fixup: `usn = u16 @ usa_off`; for `i in 1..count`: the last 2 bytes of sector `i-1` must equal `usn` (else `Corrupt`), replace with `u16 @ usa_off + 2*i`.
- Attribute header: type `u32`@0 (`0xFFFF_FFFF` = end), length `u32`@4 (0 → stop), non-resident `u8`@8, name length `u8`@9; resident: value length `u32`@16, value offset `u16`@20; non-resident: runs offset `u16`@32, real size `u64`@48.
- `$STANDARD_INFORMATION` (0x10): created `u64`@0, modified `u64`@8, file attributes `u32`@32.
- `$FILE_NAME` (0x30): parent ref `u64`@0 (low 48), name length (UTF-16 units) `u8`@64, namespace `u8`@65 (0 POSIX, 1 Win32, 2 DOS, 3 Win32&DOS), name UTF-16 @66. Prefer any non-DOS name; use DOS only if it is the only one. First non-DOS name wins (hard links ignored in v1).
- `$DATA` (0x80) with name length 0: size = resident value length, or non-resident real size.
- Data runs: header byte `h`; `len_bytes = h & 0xF`, `off_bytes = h >> 4`; `h == 0` ends; length unsigned LE; offset signed LE, relative to the previous run's LCN; `off_bytes == 0` = sparse (skip).
- Scan loop: iterate extents, read in 4 MiB chunks (multiples of cluster size), split into records, `frn = byte offset in MFT / record size`, stop at `MftValidDataLength`. Skip not-in-use records, records `0..=15` except 5 (root). Extension records (`base_frn != 0`) contribute name/size to their base (`HashMap<u64, partial>` merge at end). `progress(records_done)` every chunk.
- Mask all FRNs and parent refs with `0x0000_FFFF_FFFF_FFFF`. Root id = 5. `attrs` = SI attributes, plus `ATTR_DIRECTORY` if record flag `0x2`.
- After scan, query the USN journal (`FSCTL_QUERY_USN_JOURNAL` → `USN_JOURNAL_DATA_V0 { UsnJournalID, FirstUsn, NextUsn, .. }`) and return `Checkpoint { journal_id, next_usn }`; if the journal is not active, `checkpoint = None`.

**Walker:** `jwalk` parallel walk, `skip_hidden(false)`, `follow_links(false)`; synthetic ids starting at 1, root id 0; per-entry metadata from `DirEntry::metadata()` (size, modified, created; attrs via `MetadataExt::file_attributes`); unreadable dirs/entries increment `skipped` and continue.
